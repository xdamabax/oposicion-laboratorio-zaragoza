## 1. Encuadre

Breve situacion del tema: que norma o referencia tecnica lo regula, ambito, por
que importa para la plaza.

## 2. Desarrollo

Contenido detallado.

- Parte primera (temas 1-8): citar siempre el articulo concreto entre parentesis,
  p. ej. (art. 14 CE). Las preguntas reales son literales y por articulo.
- Parte segunda (temas 9-40): contenido operativo. Condiciones, temperaturas,
  tiempos, unidades y normas UNE/ISO por su numero.

|  |  |  |  |  |

Una fila por parametro. En "Condiciones" van temperatura, tiempo, medio de
cultivo, tipo de envase, conservacion, volumen minimo o lo que aplique.

## 4. Puntos criticos para el examen

- Cifras, plazos, temperaturas y tiempos exactos.
- Excepciones y supuestos limite.
- Confusiones tipicas entre tecnicas o entre preceptos parecidos.
